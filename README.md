# WMS 项目目录

- `ruoyi-vue-pro/`：基于官方 JDK 17 分支的 Java 后端，包含 WMS 模块；这是独立 Git 仓库。
- `wms-web/`：Vue 3 网页与 PDA 浏览器 H5 前端；这是独立 Git 仓库。
- `deploy/`：部署配置、隔离方案和验收资料。部署前需针对实际环境检查配置。

根目录 `.gitignore` 将两个独立仓库排除，避免意外把嵌套仓库当成普通目录或 gitlink 提交；后端和前端的变更需要分别在各自仓库检查和管理。不要删除或改写其 `.git` 来合并仓库。

`Linux.md`、`github.md` 含连接信息，不得提交。密码、SSH 密钥、令牌、真实环境变量、数据库备份和构建产物也不得提交；提交前分别检查根目录和两个仓库的 `git status`、差异及待提交文件。`.gitignore` 不会移除已经被 Git 跟踪的敏感文件，若已跟踪需先处理并轮换泄露的凭据。

部署约束：复用现有 Caddy、MySQL 和 Redis；使用独立数据库及账号，不删除旧数据，不占用现有项目的 80 端口。具体实施见 `deploy/部署隔离方案.md`。
